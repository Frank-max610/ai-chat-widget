❓ 常见问题

需要什么技术基础？

会复制粘贴 + 会申请 DeepSeek API Key（免费），五分钟搞定。

支持哪些网站？

纯 HTML、WordPress、Vue/React/Next.js、小程序 WebView — 反正只要是网页都支持。

能定制聊天机器人角色吗？

能。改 .env 里的 SYSTEM_PROMPT，设成客服、销售、技术支持随你。

1 核 512M 最低配云服务器就够了，阿里云/腾讯云几十块一个月。
